칠죄종 — THE SEVEN SINS
========================
GitHub Pages용 정적 사이트입니다.

구성
- index.html : 메인 소개 페이지
- member.html : 멤버 상세 페이지 (예: member.html?id=01)
- style.css : 전체 디자인 + 모바일 반응형
- script.js : 멤버 데이터, 카드/모달, 모바일 메뉴
- assets/ : 단체 배너 및 7명 개인 일러스트

멤버 순서
01 김캐마 / 질투
02 대부기 / 분노
03 문향단 / 탐욕
04 이정잭 / 오만
05 아랑 / 색욕
06 우현 / 식욕
07 개 / 나태

GitHub Pages 배포
1. 이 폴더의 파일을 저장소 루트에 업로드합니다.
2. Settings > Pages에서 Branch를 선택합니다.
3. index.html이 있는 브랜치를 배포 대상으로 지정합니다.

상세 페이지는 별도 HTML을 만들지 않고 member.html?id=01~07 방식으로 동작하므로 GitHub Pages에서도 그대로 사용할 수 있습니다.
