칠죄종 — THE SEVEN SINS

GitHub Pages 배포용 완성본

이번 수정본은 GitHub Pages에서 style.css / script.js가 로드되지 않아 글만 보이는 문제를 피하도록 index.html과 member.html에 CSS/JS를 직접 포함했습니다.

구성:
- index.html : 메인 홈페이지
- member.html : 멤버별 상세 페이지 (?id=01~07)
- assets/ : 단체 배너 및 7명 일러스트
- style.css / script.js : 원본 소스 파일도 함께 제공

배포:
1. 이 ZIP의 파일 전체를 GitHub 저장소 루트에 업로드합니다.
2. assets 폴더도 반드시 함께 업로드합니다.
3. GitHub Pages가 main 브랜치 / 루트를 배포하도록 설정되어 있는지 확인합니다.
4. 배포 후 브라우저에서 Ctrl+F5로 강력 새로고침합니다.
